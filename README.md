# GlassM / GlassX

Casualties Unknown 流式生成性能模组。**GlassM**(标准版)与 **GlassX**(激进版)是同一模组的两种形态,二选一安装。

核心功能相同:替换原版全层加载的世界生成,改为以玩家为中心的流式生成,大幅降低生成开销。

## 核心功能(两版共有)

- **流式世界生成**:以玩家(联机时以所有玩家)为中心,区块按需生成/卸载,取代原版一次性全层生成
- **物理区动态开关**:远离玩家的区块关闭 collider/刚体模拟,刚体负担从 256 块大幅下降
- **初始 2×2 快速出生**:出生只需 4 块同步生成,进图更快
- **原版参数对齐**:地形/矿石/地表装饰物与原版一致
- **荆棘背平衡**:主动生物预警/遭遇范围恢复原版水平
- **PerfDiag 诊断**:每 5 秒输出各系统耗时(wg/fluid/body)、FPS、场景负载
- **联机兼容**(KrokoshaCasualtiesMP):以所有玩家为中心生成/保护,客户端玩家不会因主机卸载区块而掉落
- **结构修复**:跨块结构渲染与碰撞同步正确

## 版本差异

| 配置项 | **GlassM(标准版)** | **GlassX(激进版)** |
|---|---|---|
| 生成区 | 7×7 | **5×5** |
| 物理区 | 7×7 | **5×5** |
| 每帧生成 | 4 块 | **8 块** |
| 渲染区 | 3×3 | 3×3 |
| 渲染缓存 | 无 | **有**(往返复用,不重复构造) |
| 渲染分辨率 | 原样 | **85%**(URP renderScale) |
| 画质档 | 原样 | **最低档** |
| 视线分辨率 | 原样 | **减半** |
| 物理迭代 | 原样 | **减半**(velocity 4 / position 2) |
| 流体模拟 | 每物理帧 | **隔帧**(开销减半) |
| 着色器 | 原样 | **复杂 shader 全换 Unlit**(无光照) |

## 视觉/体验代价(仅 GlassX)

- 无 2D 光照(手电筒/火光等光照效果消失)
- 流体表面效果简化(已保持半透明)
- 画面轻微模糊(85% 分辨率)
- 物理迭代降低,极端情况可能有轻微穿透
- 荆棘背活动区缩小到 5×5

## 安装

1. 杀游戏进程,二选一:
   - 标准版:`GlassM.dll` → `BepInEx\plugins\`
   - 激进版:`GlassX.dll` → `BepInEx\plugins\`
2. 启动游戏,日志出现 `GlassM loading` 即生效

**注意**:两 DLL 插件 ID 相同(`com.cu.glassm`),不能同时安装。

## 推荐

- 中高端机器 / 追求画质:**GlassM**
- 低配机器 / 追求帧率:**GlassX**(可接受无光照与模糊)

## 构建

```
dotnet build -c Release --nologo -v q
```

产物 `bin\Release\GlassM.dll`。激进版位于 `aggressive` 分支,构建后改名为 `GlassX.dll` 分发。

## 分支

- `main` — 标准版 GlassM
- `aggressive` — 激进版 GlassX
